## v0.20.0-custom.5 (2026-10-16)

基于上游 marktext **v0.20.0 正式版**（tag `v0.20.0`）的第五个自定义版本。

### 本版新增

**当前目录面板升级为懒加载目录树 + 固定目录**

侧栏「当前目录」（Current Directory）面板从「平铺列出当前文件所在目录的 Markdown 文件」升级为**可展开的目录树**：

- **目录树懒加载**：目录全部显示、文件只显示 Markdown（按扩展名白名单）；展开某个目录才扫描该层，目录内容再多也不卡（不递归预读）
- **会话内记忆展开状态**：切换文件、切到别的目录再切回、或切走侧栏面板再回来，已展开的目录和已加载内容都保留
- **固定目录（Pin）**：勾选「固定目录」后，面板不再跟随打开的文件跳根——打开子目录里的文件也不会把树切走；取消勾选立即回到当前文件所在目录。悬停勾选项有说明提示
- 刷新按钮重扫根目录及所有已展开的子目录（扫描中保留旧内容不闪烁）

### 修复与改进

- **交换 Current Directory 与 Workspace 的侧栏图标**：当前目录改用文件夹图标、工作区改用文件图标，语义更贴合
- **修复两个面板标题顶进窗口标题栏**：Current Directory / Workspace 面板内容此前从窗口最顶部开始，与标题栏的路径/文字统计重叠；现在统一留出标题栏高度

### 已知问题

- 未签名构建：Windows SmartScreen 可能告警，需手动允许；macOS 未公证，首次打开需右键 → 打开
- 「当前目录」面板的树会**始终忽略** `node_modules` / `.git` / `.hg` / `.svn` / `*.asar`，其余目录全部显示；非 Markdown 文件不显示
- 「固定目录」是会话级状态（不落盘），重启应用后恢复为跟随当前文件
- `preserveFormattingOnSave` 的原文回放作用于**顶层块**：编辑表格某个单元格后，整个表格会按规范重排（未被编辑的表格不受影响）；「源码模式」不受此机制影响
- 数学偏好不向后兼容：旧配置项 `math` 与「GitLab 兼容」开关已被 `texMath*` 系列取代，升级后需按需重设
- 本机（Windows）发布前检查实测数字（环境相关，与本次改动无关的浮动忽略不计）：
  - desktop 单测 `pnpm run test` **999 通过 / 0 失败 / 36 跳过**
  - `pnpm run lint` **0 error**（169 warning 为上游既有基线）；`pnpm run typecheck` 通过；`pnpm run build:unpack` 通过
