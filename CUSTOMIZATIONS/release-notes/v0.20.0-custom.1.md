## v0.20.0-custom.1 (2026-09-04)

基于上游 marktext develop@1d3025b2（0.20.0 开发线）的首个自定义版本。

> 预发布说明：基线是上游 develop 分支提交（非正式 tag），功能未经完整回归，建议先在非关键环境使用。

### 自定义改动

- **保存时保留未修改行的原始格式（preserveFormattingOnSave，默认关闭）**
  - CUSTOM-20260904-004：设置 → Markdown → Lists 新增开关「保存时保留未修改行的原始格式」。打开后，WYSIWYG 模式保存时未修改的块按原文逐字节回放（表格列宽、多空行、`~~~` 围栏、引用前缀、ATX 关闭式等全部保留）；被编辑的块仍按规范序列化
  - CUSTOM-20260904-005：修复两类边界——0 空行块边界（如标题后紧贴段落）被强制插入空行、文档尾部空行丢失
  - 原理：解析时在块状态上记录原文锚点（token.raw + 块间空行数 + 文档尾部空行数）；muya 编辑走 ot-json1 op 只触达被编辑块，未改块锚点天然保留；保存时一致性校验通过则回放原文

- **修复两个上游 bug（Windows 打包版启动失败，CUSTOM-20260904-003）**
  - `globalSetting.ts` 的 `.replace(/\\/g,'\\\\')` 把 Windows 资源路径破坏成双反斜杠，打包版启动报 "Can not load static preference.json file"（Startup error 对话框）
  - pnpm 隔离布局下 `@vscode/ripgrep-win32-x64` 平台包进不了 electron-builder 的 asar，启动报 "Could not find @vscode/ripgrep-win32-x64"（该修复也是打 Windows 包的前置条件）

- **自定义开发体系（CUSTOMIZATIONS，CUSTOM-20260904-001/002）**
  - 文档体系（规则/账本/代码地图/坑点库）、AI skills（record-change / merge-upstream / release）、本地打包脚本套件（manager.sh / build-unpacked.bat / build-setup.bat）
  - 仓库结构：vendor/develop（上游镜像）+ custom/main（自定义主线），参考 chatbox 自定义仓库机制

### 已知问题

- 未签名构建：Windows SmartScreen 可能告警，需手动允许
- `preserveFormattingOnSave` 的原文回放作用于顶层块：编辑表格某单元格后整个表格按规范重排（非编辑表格不受影响）；「源码模式」不受此机制影响（本就原样保存）
- 其余 11 种界面语言的新开关文案暂用英文兜底（en/zh-CN 已翻译）
