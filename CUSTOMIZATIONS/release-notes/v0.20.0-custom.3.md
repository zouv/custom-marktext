## v0.20.0-custom.3 (2026-10-08)

基于上游 marktext **v0.20.0 正式版**（tag `v0.20.0`，2026-10-02 发布）的第三个自定义版本。

> **与上一版的关键区别**：基线从开发线提交（`develop@1d3025b2`，即 v0.19.0-361）换成上游**正式发布 tag**，本版起不再带「基线是开发线、未经完整回归」的预发布警告。
>
> 上游这一个版本改动量很大（177 提交 / 547 文件），编辑器内核已整体迁移到 TypeScript 重写版 `@muyajs/core`，旧的 `packages/muyajs` 已无引用（上游计划在 0.20.0 之后删除）。

### 本版新增

**上游 v0.20.0 带来的功能**

- **Pandoc 导出**：Markdown 转任意格式；配套重做数学偏好——以 `texMathDollars`（`$…$`）、`tex_math_gfm`（``$`…`$`` 与 ` ```math ` 围栏）、单/双反斜杠 `\(…\)`、`\[…\]` 取代旧的 `math` 开关与 GitLab 兼容选项
- **图表体验**：渲染图（Mermaid / PlantUML / Vega 等）支持缩放、平移查看，并可导出为图片
- **编辑体验**：TOC 随光标位置高亮当前标题；选中文字显示字数；源码模式行号开关；「把软换行当作空格」偏好
- **语法支持**：有序任务列表（#1691）、波浪号（`~~~`）代码围栏（#1788）、同行行间公式
- **平台相关**：macOS 选中文字查词典；Window 菜单新增 Reset Zoom；PlantUML 服务器地址可配置
- **界面语言**：新增俄语（11 → 12 种语言）
- 编辑器内核换代：渲染器改用 `@muyajs/core`，同时补齐焦点模式、图表主题化、统一样式等能力

**自定义侧**

- **保真回放适配新内核**：上游把数学选项从 `math` / `isGitlabCompatibilityEnabled` 重构为 `texMath*` 系列，`preserveFormattingOnSave` 的整条透传链（解析器 lexer 选项、`_anchorRawSource`、序列化器重解析选项）随之迁移（CUSTOM-20260904-004/005）
- **俄语补齐自定义键**：`sideBar.currentDir.*`、`sideBar.icons.currentDir`、`preferences.markdown.lists.preserveFormattingOnSave` 的俄语翻译，12 种语言键位与 `en.json` 完全一致

### 修复与改进

- **打包脚本重试机制修复（两个真实缺陷）**
  - `build-unpacked.bat` / `build-setup.bat` 的抗杀软退避写成 `timeout /t 15`。从 Git Bash 调用时（`manager.sh` 正是这条路径）PATH 上的 `timeout` 是 GNU coreutils 版本，会因 `/t` 非法**立刻返回**——「等待 15 秒」实际是 0 秒，三次重试全挤在杀软扫描窗口内。改用 `%SystemRoot%\System32\timeout.exe` 并保留 `ping` 兜底
  - 重试前不清理上一次失败留下的半成品 `dist\win-unpacked\`，导致第 2/3 次必然卡在暂存目录改名（`EPERM`）。现在每次尝试前先清空
  - 实测：修复前连挂 3 次（死法各不相同）；修复后 `EXIT=0`，产物 `FileVersion` 与版本号一致
- 文档与配置：更正 registry 中的语言数（11 → 12）；`.gitignore` 并入上游新增的 `.codex/` 忽略规则

### 已知问题

- 未签名构建：Windows SmartScreen 可能告警，需手动允许；macOS 未公证，首次打开需右键 → 打开
- `preserveFormattingOnSave` 的原文回放作用于**顶层块**：编辑表格某个单元格后，整个表格会按规范重排（未被编辑的表格不受影响）；「源码模式」不受此机制影响（本就原样保存）
- **数学偏好不向后兼容**：旧配置项 `math` 与「GitLab 兼容」开关已被 `texMath*` 系列取代，升级后需按需重设
- 本机（Windows）实测数字（环境相关基线，与本次改动无关）：
  - desktop 单测 `pnpm run test` 全量并发下 **966 通过 / 6 失败 / 36 跳过**；6 个失败全部落在 `pdf.spec.ts`(5) 与 `theme-emoji-patch.spec.ts`(1)，隔离重跑（放宽超时）**21/21 全过**；同一提交在机器空闲时曾跑出 **972 通过 / 0 失败**
  - muya 单测 2386 用例在默认 5s 超时下有 **2 个超时**（上游自带的 `diagramLanguage` 与 `tableChessboard`），放宽超时后 **14/14 全过**
  - 二者均为本机模块转换慢导致的浮动超时，在 Linux CI 上通过，不影响本页构建产物
